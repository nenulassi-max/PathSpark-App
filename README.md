What is PathSpark?
PathSpark is a job and internship search portal that allows users to find jobs in their area 
using a certain keyword.

Why I Built PathSpark?
I was inspired to build PathSpark because, as a young adult, I have seen the immense amount of time and energy 
that it takes to search for and apply for jobs and internships. 
I understand as a young adult that finding internships that relate to your speciality are very hard to find. 
Which is why I created PathSpark. 

What features does this app have?
- Job list
- Zip code search
- Keyword speciality
- Save specific searches

Tech Stack:
- Swift
- SwiftUI
- MapKit
- CoreLocation
- Foundation
- URLSession

PRECAUTIONS:
The API key used to make these searches has a limit of 30 searches per hour. 
Each search gives about 25 jobs.
